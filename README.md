# Personal Website of Manmeet Singh Heran

Welcome to my personal website! I'm Manmeet Singh Heran (previously Manmeet Singh), sharing thoughts on neuroscience, physiology, and technology through blog posts and writings.

This site is built with [AstroPaper](https://github.com/satnaing/astro-paper), a minimal Astro blog theme.

## About

- **Blog**: Explore my posts on learning theory, brain function, and more.
- **About**: Learn more about my background and interests.
- **Contact**: Connect via social links.

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Search**: [PageFind](https://pagefind.app/)
- **Deployment**: [Cloudflare Pages](https://pages.cloudflare.com/)

## Getting Started

To run this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/your-repo.git
   cd your-repo
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   pnpm run dev
   ```

Visit `http://localhost:4321` to view the site.
